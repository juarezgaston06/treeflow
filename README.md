# Treeflow

Landing page para Treeflow, un servicio de automatización de procesos y creación de agentes de IA a medida para negocios.

## Qué incluye

- `index.html` — estructura de la landing (hero, servicios, proceso, casos de uso, FAQ, contacto).
- `css/styles.css` — estilos, con soporte de modo claro/oscuro.
- `js/main.js` — pequeños detalles de interactividad (año dinámico en el footer).

## Cómo verla en local

No requiere build ni dependencias. Alcanza con abrir `index.html` en el navegador, o servirla con cualquier servidor estático:

```bash
npx serve .
```
